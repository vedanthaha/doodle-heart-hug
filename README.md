# A Little Corner

Build a complete multi-page emotional comfort website for my close female friend. The purpose is to cheer her up after a rough personal situation and remind her:



“I’ll still be here for you, no matter what happens. You don’t have to deal with everything alone. ❤️”



The website should feel like a personal handmade digital scrapbook / doodle letter, as if I created it for her myself.



IMPORTANT:



- This must NOT look AI-generated, corporate, generic, or like a template.

- Do NOT use random stock images.

- Do NOT use PNG illustrations.

- Do NOT use random external images.

- All visual artwork must be created using CSS, inline SVG, HTML elements, or canvas so the illustrations feel intentionally designed and lightweight.

- Do NOT make it a single-page website.

- Every page must feel complete and intentionally designed.

- No unfinished sections, placeholder components, lorem ipsum, empty cards, broken animations, or fake buttons.

- Everything must be responsive and polished on mobile first.

- The final result should feel like a premium interactive handwritten website.



TECH STACK:



- React

- TypeScript

- Tailwind CSS

- Framer Motion

- React Router

- Inline SVG / CSS illustrations for all doodle artwork

- Use Lucide icons only when an icon is actually needed



OVERALL ART DIRECTION:



Create a warm handmade doodle aesthetic.



Visual language:



- Off-white / paper background

- Slight paper grain using CSS only

- Black/dark graphite doodle outlines

- Small accents of soft red, pink, muted yellow and blue

- Handwritten-looking typography paired with a clean readable font

- Slightly imperfect borders

- Hand-drawn arrows

- Stars

- Hearts

- Clouds

- Tiny flowers

- Tape / sticky-note motifs

- Little smiley faces

- Scribbles

- Underlines

- Hand-drawn circles around important words



Avoid:



- Glassmorphism

- Neon gradients

- Huge blobs

- Excessive rounded UI cards

- Generic AI landing-page aesthetics

- 3D illustrations

- Stock photography

- Random decorative images



The page should look like a real person made it with a notebook, black pen and colored markers.



TYPOGRAPHY:



Use a combination of:



- One handwritten / playful display font for headings

- One clean modern sans-serif for body copy



Typography should have strong hierarchy.



Do NOT use giant text that consumes the whole screen.
